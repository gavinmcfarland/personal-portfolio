Showing a UI window

To show a UI window we can call one using the following function.

figma.showUI('<p>Hello world</p>')

When we show the UI we need to pass in a string.

We can also replace this string with the __html__ keyword which points to a html file inside our manifest.json file.

{
    //...
    "ui": "ui.html"
}

Using the __html__ keyword will then display the UI inside ui.html.

In the example on the right, try changing it to use the __html__ keyword as shown below.

figma.showUI(__html__)
After completing this step you'll need to re-open the plugin.
