The occupation of the sheet

The type is the artefact.
The rest is where the hand goes.

A galley proof is set in one long column on a sheet far wider than the column needs, so the corrector has somewhere to write. Nothing on this page is centred by default and nothing fills the width because it can. Each frame below takes a viewport and spends it differently.

— occupations · one viewport each · press G for the grid

Note Emptiness here is not restraint for its own sake. It is the margin a proof needs, kept because the content is the thing being judged.
