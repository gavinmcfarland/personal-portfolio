Design systems, developer tooling, and the seam between them

The lead

I build the tools design systems are made with — and the systems themselves.

Fifteen years spent between design and front-end, mostly on the seam: token pipelines, component APIs, and the editor plugins that keep the two halves honest with each other.

The tools on this sheet were all built the same way — because a problem kept recurring, and because the thing that would have fixed it did not exist yet.
