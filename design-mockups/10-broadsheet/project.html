01

The problem

A Figma plugin is two programs that cannot see each other. One runs in a sandbox with access to the document; the other runs in an iframe with access to the DOM. They speak only by passing messages, and neither can be served from disk the way an ordinary web app can.

So every plugin began with the same lost day: a bundler, a manifest, a message bridge, and a build step that inlines the UI. Change a line, rebuild, re-run, lose your state.

02

What it does

Panels cross their own columns

This is the only place in the set where blocks are allowed to break out of their column and stack over each other. It earns the exception because the subject is two halves overlapping — the shape is the argument.

01 Scaffold

One command produces a working plugin — manifest, bundler and bridge already wired.

02 Develop

The UI is served from a dev server. Edits appear without a rebuild, and the plugin keeps the state you were testing against.

03 The manifest is the seam

In development it points at a dev server; at build time it points at inlined output. It is the only file that differs between the two modes.

04 Framework-agnostic

React, Svelte, Vue, or none at all.

05 Ship

The same UI is inlined into the output. The sandbox half never notices the difference.

06 The point

Interface work stops being a stop-start loop. That is the whole return on the tool.
