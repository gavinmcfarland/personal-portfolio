NAME

specimen — design specimen for gavin(1); paper, ink, monospace and a single dark-green cursor, laid out for comparison rather than reading

Direction: the portfolio as a manual page, set entirely in one monospace face on warm paper rather than a black terminal. This sheet is that mockup reduced to raw material — every colour, size and component it is built from, so it can be held next to the others.

PALETTE

Six tokens, each with a light and dark value, toggled by one class on <html>. Click the sun/moon in the invocation bar to see them swap.

paper
Page background — light, dark
ink
Primary text — light, dark
muted
Secondary text, body copy in DESCRIPTION-style prose — light, dark
faint
Tertiary / meta text, captions, years — light, dark
leaf
The one accent — prompt glyph, xref hover, focus ring, active TOC rail — light, dark
rule
Hairline borders between chrome bands — light, dark

TEXTURES

The illustrated variant (gavin-illustrated(1)) draws every figure as block glyphs — ░▒▓█ — quantised through a 4×4 Bayer matrix so density carries tone the way it does in a terminal image viewer. Nothing here is a raster; it is text, seeded per project so a given plate never reshuffles.
