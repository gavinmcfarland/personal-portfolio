01 specimen plate drafting

A drafting sheet, not a document.

Plate drafting is a hairline-ruled, zero-radius, zero-shadow system: a 12-column sheet grid and a 24px baseline, flat plates instead of floating cards, and a single vermilion accent used only for annotation — numbers, links, the caret that appears on hover. IBM Plex Sans carries reading text; IBM Plex Mono carries every label, key and value, so the sheet reads like a technical drawing rather than a brochure.

Below: every token, family, size step and component this mockup actually uses, live. See index.html for the sheet this specimen is drawn from.

06 grid & rules press g

The only texture in this system is structural: hairline rules (--rule, --rule-hair) and the 12-column / 24px baseline grid, overlaid on demand with the grid button in the header or the G key. The board (§05) uses a denser 20px‑minor / 100px‑major line grid, sunk one shade below paper.
