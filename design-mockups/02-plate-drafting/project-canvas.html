03 problem

A Figma plugin is two programs that cannot see each other — one in a sandbox with the document, one in an iframe with the DOM. They speak only by passing messages.

So every plugin began with the same lost day: a bundler, a manifest, a message bridge, and a build step that inlines the UI.

04 approach

Plugma hides that underneath. One command scaffolds, one develops, one ships, and the framework stays your choice.

The part worth having is real hot module reloading — edits appear without a rebuild and without losing plugin state.

05 result

The setup it replaces took most of a day. It now takes a command. Still maintained, and the substrate for every plugin I built after it.
