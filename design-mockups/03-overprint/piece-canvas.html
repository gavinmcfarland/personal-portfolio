03constraints

A plugin is two programs that cannot see each other — one in a sandbox with the document, one in an iframe with the DOM. They speak only by passing messages.

Neither half can be served from disk, so the UI has to be inlined into the built file.

04build

One command scaffolds, one develops, one ships. In development the UI is served; at build time it is inlined. The sandbox half never notices.
