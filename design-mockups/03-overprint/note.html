Two programs, one plugin

A Figma plugin looks like one thing and behaves like two. Almost every difficulty in building one comes from that gap, and almost every tool that helps is a tool that hides it.

The split

When a plugin runs, Figma starts two separate programs. The first runs in a sandbox with access to the document — nodes, selection, pages — and no DOM at all. The second runs in an iframe with a full DOM and no access to the document whatsoever.

They cannot call each other. They cannot share objects. Everything that crosses between them is a message, serialised on the way out and parsed on the way in.

The sandbox knows what the user selected. The iframe knows what the user clicked. Neither knows both.

What that costs

The obvious cost is ceremony. Any behaviour that spans both halves needs a message type, a sender, a listener, and a shape agreed in two places at once: 

// sandbox half — document access, no DOM
figma.ui.onmessage = (msg) => {
  if (msg.type === 'resize') {
    figma.ui.resize(msg.w, msg.h)
  }
}

The less obvious cost is the build. Neither half can be served from disk the way an ordinary web app can, so the UI has to be inlined into the built file before Figma will load it. That single requirement is what breaks the development loop, because inlining is a build step, and a build step means you are no longer editing — you are rebuilding and reloading, by hand, every time.

What a toolchain has to hide

So the job is not to make the split easier to think about. It is to make it invisible during development and correct at build time. Three things have to be true:

  • In development, the UI is served, not inlined — so it can hot reload.
  • At build time, the same UI is inlined — so Figma will accept it.
  • The sandbox half cannot tell which of those two just happened.

Get those right and the loop closes: you change a line and you see it, with the plugin state you were testing against still intact. That is the whole return. Everything else the tool does is bookkeeping.

Plugma is my attempt at exactly that, and the working board is where the argument was worked out before any of it was written.
