03 method three rules

draw it first If I cannot draw the problem, I do not understand it yet. Every project starts in a design file, including the ones that end as a command-line tool.
leave it documented The work is not finished when it ships. It is finished when the next person can change it without asking me anything.
own the gap The interesting problems sit between design and engineering, where nobody has been given the job. That is usually where I end up.
