Long-form furniture

Body copy sits in the muted ink; strong pulls back to full ink. The measure is set by the grid, not by a guess.

The sandbox knows what the user selected. The iframe knows what the user clicked. Neither knows both.

// sandbox half — document access, no DOM
figma.ui.onmessage = (msg) => {
  if (msg.type === 'resize') {
    figma.ui.resize(msg.w, msg.h)
  }
}
  • In development, the UI is served — so it can hot reload.
  • At build time, the same UI is inlined — so Figma accepts it.
  • Bullets are marked in ink B.
