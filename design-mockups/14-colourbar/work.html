01 Name work(1)

work — — tools, libraries and plug-ins, each one begun because the thing that would have fixed the problem did not exist.

02 Synopsis

$ gavin --list [--tool | --library | --plug-in]

03 Description t5 · entry

Each entry carries the strip it was drawn for. The geometries are described under colour(7); the ink is the project's, not the category's.

04 Register t2 · ledger

The same — again, without the pictures. An 8px swatch names the category, so the column can be scanned for one kind of thing without reading a word of it.
