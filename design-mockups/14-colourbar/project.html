01 Name plugma(1) · 2024

plugma — build Figma plugins with a single command and the hot reloading the platform never shipped.

04 Description

A plugin is two programs that cannot see each other. One half runs in a sandbox with access to the document and no DOM; the other runs in an iframe with a DOM and no document. They talk through a message channel, and every difficulty in building one comes from that arrangement.

Plugma puts the bundler, the manifest and the message bridge underneath one command, and — the part that actually changes the work — keeps the plugin's state alive across an edit. The UI is served from a dev server while you work and inlined at build time, so the sandbox half never notices the difference.

Interface work stops being a stop-start loop. That is the whole return on the tool.
