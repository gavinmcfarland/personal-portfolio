About

I sit in the gap between design and engineering — the place where a beautiful spec meets the reality of shipping it. I have spent fifteen years there, and it turns out the gap is where most of the interesting problems live.

The pattern repeats: a team is slowed by something nobody owns. A design system with no source of truth. A plugin toolchain that takes a day to configure. So I build the missing tool. Plugma came out of that instinct and now underpins Figma plugins across the community.

Lately I write more code than pixels, mostly TypeScript, Svelte and Node — but I still start every project in a design file, because a problem you cannot draw is a problem you do not understand yet.
