specimen

Flat — one typeface, one size, one edge.

The direction in one sentence: body, headings and data all sit at the same size, and structure is carried by case, weight, colour and vertical space instead of scale. This page shows the tokens and components that make that argument.

Type scale

The hierarchy is almost flat by design. Exactly one element is allowed to step up — the opening statement — everything else, from section markers to body copy to the footer, sits at the same base size.
