Type scale

Flat type. Two sizes, plus one step for command lines — headings get weight and letter-spacing, never a bigger number.

Dither fields

Six 1-bit plates, each a square-dot base with two coarser grids masked into repeating geometry. No dot is round; where a circle appears it is a true circle cut with an explicit pixel radius.

a — grid

b — band

c — fine

d — disc

e — moiré

f — block

Grounds

The same dots at roughly a third the ink, poured behind a whole section so the sheet reads as printed matter rather than a flat background colour.
