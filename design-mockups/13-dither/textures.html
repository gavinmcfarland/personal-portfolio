Name

dither — the 1-bit fields, decals and grounds this set is illustrated with.

Description

Every picture in this folder is made of dots that are either present or absent. There are no photographs, no icons, and no flat blocks standing in for an image that was never going to arrive.

The dot is a square. A dither is a decision made per pixel, and a pixel is square — so every mark in every field below is a square, cut from the first quadrant of a conic gradient. There is not one round dot in the engine.

The clumping is ordered. Denser passages are not scattered about; they are masked into repeating geometry — checkerboards of rectangles, grids of true circles, and horizontal bands — so a field reads as something built on a grid rather than as noise that happened. Where a circle appears it is cut with an explicit pixel radius, so it stays perfectly round whatever the shape of the box around it.

Nothing here fades. Every colour stop is hard, which is not a restriction the technique had to work around — it is the definition of dithering, and the reason this engine sits comfortably inside a system that has banned gradients since 09.

Fields

— of them. They are not interchangeable: each was tuned so its clumping reads at the size the entry prints it, and the note beside each one is the honest account of where it fails.

Scale

One field — grid — at four crops. The dot pitch and the 72px checkerboard behind it never change, so a small plate shows a fragment of the structure rather than a shrunken copy of it. The fields behave like a photograph being cropped, not like artwork being scaled.

Decals

— small marks, each meant to be placed half off the edge of something rather than tidily inside it. Everything else in this set is deadpan; these are where it is allowed to enjoy itself. Shown below in place rather than in a swatch grid, because a decal that is not overlapping anything is just a shape.

A true circular ring, stamped over a corner: approved, current, finished.

seal

Register marks in the margin. Says “this is a proof” and nothing else.

crop

A checkered rectangle hanging off the top edge, the way a sticker does.

tab

A rectangle and a true circle, breaking the box they are placed on.

chip

A band with weight, for when a hairline is too quiet.

stripe

Grounds

The same engine at roughly a third the ink, poured behind a whole section so the sheet reads as printed matter rather than as a background colour. Grounds always sit behind running text, so they get their own much weaker value — a field you can read a paragraph through is the entire point.

ground--patch

Cut off at one edge by a hard-stop ellipse mask, anchored right so it never sits under the first line of an indented block.

ground--band

Masked into horizontal bands, so the field reads as ruled paper seen from a distance. Used for reference sections such as ENVIRONMENT.

ground

Unmasked and even. The quietest of the three, and the only one safe to run underneath a long passage.
