Eight ways to say “this one matters more” without changing the type size.

This system has no display size. The largest type on any sheet in this folder is 15px, and every heading — including the one above — is set at it. Rank has to come from somewhere else, so it comes from these.

The rule

11px · 12px · 15px

Three sizes, four pixels apart. Ornamental numerals are excluded because they carry no meaning.
