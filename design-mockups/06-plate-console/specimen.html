01the set —

Every icon is a grid of characters, one character per pixel, in a source file you can read and diff. The two sizes are drawn separately, not scaled — a 32×32 reduced to 16px puts every source pixel on a half-pixel and turns to mud.

02detail 32 × 32, magnified

Shading is done with the palette's own steps — white, silver, gray, black — because a 16-colour icon has no alpha to spend. Pick a cell to inspect it.

04rules
one source Icons live in icons.js as character grids. No sprite sheet, no icon font, no build step.
draw each size 16 and 32 are separate drawings. The small set carries fewer details and heavier forms so it survives at 16px.
palette only Sixteen colours, no gradients, no alpha. Shading is done by stepping through the palette.
stay aliased shape-rendering: crispEdges — antialiasing is the one thing that would give a bitmap away.
merge runs Horizontal runs of one colour become a single <rect>, so a 32×32 cell is tens of rects, not 1,024.
